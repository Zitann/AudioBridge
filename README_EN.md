# AudioBridge

[中文](README.md) | [English](README_EN.md)

Windows tray application: connect your phone to PC via Bluetooth, stream phone audio to PC speakers.

Built on Windows 11 `AudioPlaybackConnection` WinRT API.

## Use Case

When playing competitive games like Valorant or CS:GO, during those few seconds waiting to respawn:

- **No need to remove headset** — phone audio plays through PC speakers/headset directly
- **No need to switch Bluetooth** — phone stays bridged to PC, game voice and phone music don't interfere
- **Scroll TikTok during respawn** — when the respawn sound hits, switch back instantly, never miss the timing

## Requirements

- Windows 11 22000 or later
- Phone already paired in Windows Bluetooth settings

## Usage

1. Double-click `AudioBridge.exe` to run, a blue speaker icon appears in system tray
2. Right-click icon → **Bluetooth settings**, confirm phone is paired
3. Right-click icon → click phone name to connect
4. After connected, phone music/video audio plays through PC speakers
5. Click device name again to disconnect; click **Exit** to disconnect all and quit

## Project Structure

```
AudioBridge/
├── main.go          # Entry point, systray lifecycle, message box
├── app.go           # Tray menu logic: device list, connect/disconnect, status display
├── a2dp.go          # Go wrapper for a2dp_bridge.dll (go:embed + syscall)
├── icon.go          # Program-generated tray icon (blue speaker, PNG→ICO)
├── icon.ico         # Generated icon file (embedded into exe via rsrc)
├── app.manifest     # DPI awareness + Win11 compatibility declaration
├── rsrc.syso        # Resource file generated by rsrc, auto-linked by go build
├── go.mod
├── go.sum
├── a2dp-bridge/     # C++/WinRT DLL source and header
│   ├── a2dp_bridge.cpp
│   ├── a2dp_bridge.h
│   └── a2dp_bridge.dll
└── .github/workflows/build.yml   # GitHub Actions auto-build DLL
```

## Architecture

```
┌───────────────┐      ┌──────────────────┐      ┌─────────────────────────┐
│  AudioBridge  │────▶│ a2dp_bridge.dll  │────▶│ AudioPlaybackConnection │
│  (Go tray app)│      │ (C ABI wrapper)  │      │ (Windows 11 WinRT API)  │
└───────────────┘      └──────────────────┘      └─────────────────────────┘
```

- Go program calls DLL exported C functions via `syscall.LoadDLL`
- DLL embedded into exe via `go:embed`, extracted to `%TEMP%\AudioBridge\` at runtime
- Single-file distribution, no extra DLL needed

## Development

### Requirements

- Go 1.21+ (pure Go, no CGO)
- Windows 11 (dev/test)
- GitHub Actions (auto-build DLL, no local MSVC needed)

### Build

```bash
# 1. Get dependencies
go mod tidy

# 2. Build (rsrc.syso already provided, auto-linked by go build)
go build -ldflags="-H windowsgui -s -w" -o AudioBridge.exe .
```

### Regenerate icon and rsrc.syso

```bash
# Install rsrc tool (one-time)
go install github.com/akavel/rsrc@latest

# Generate icon
go run genicon.go

# Pack resources
rsrc -manifest app.manifest -ico icon.ico -o rsrc.syso
```

### Rebuild a2dp_bridge.dll

DLL source in `a2dp-bridge/` directory. Push to GitHub and Actions will auto-build:

```bash
git add a2dp-bridge/a2dp_bridge.cpp
git commit -m "feat: update A2DP bridge logic"
git push
# Download compiled a2dp_bridge.dll from GitHub Actions
```

Local build (requires Visual Studio 2022 + Windows SDK):

```cmd
cl.exe /std:c++20 /EHsc /O2 /LD a2dp-bridge/a2dp_bridge.cpp /link /OUT:a2dp-bridge/a2dp_bridge.dll
```

## Known Limitations

- Windows 11 22000+ only (`AudioPlaybackConnection` API requirement)
- Only supports paired Bluetooth audio devices
- Audio latency depends on Bluetooth codec and system buffering
